## ⚙️ Installation & Termux Setup
Instalação direta e compatível nativamente com ambientes Linux, Kali Linux e Termux:

```bash
# 1. Clonar repositório e acessar diretório
git clone <repo_url>
cd aegis-de

# 2. Ativar Ambiente Virtual e Instalar Dependências
python3 -m venv ~/crewai-env || true
source ~/crewai-env/bin/activate
pip install -r requirements.txt

# 3. Iniciar Servidor Local Ollama
ollama serve > /dev/null 2>&1 &
sleep 3
```

## 🔐 Security Model & Zero-Trust Audit
- **Classification**: DEFENSIVO
- **Higiene Digital**: Verificações passivas e diagnósticas de segurança de rede
- **Mitigações Ativas**:
  - *Ameaça:* Hacker exploit via Clickjacking → *Mitigação:* Inserção do Header X-Frame-Options: SAMEORIGIN nas respostas ou CSP Content-Security-Policy frame-ancestors
  - *Ameaça:* Exposição Man-in-the-Middle (MitM) → *Mitigação:* Forçar Strict-Transport-Security com max-age longo de pelo menos 1 ano (31536000)
